## 说明

- 每篇笔记同时提供 Markdown 与 PDF：Markdown 供网页直接阅读、搜索和按行比对；PDF 保留原始排版，原文中的配图和截图只存在于 PDF 中。
- 内容为个人阅读笔记，原文出处写在每篇开头。
- 笔记记录的是个人理解，可能存在偏差，欢迎在 Issues 中指正。

## 关于原文与版权

本仓库的笔记是对第三方文章的**知识点拆解**，不是原文转载。例如第 01 篇拆解的是 tmp0ut 首刊第二篇文章（https://tmpout.sh/1/2.html），文中保留了原文链接与结构，内容以个人复述、验证和补充为主。
